DUCKY CHEATSHEET

REM [text]: Display text on BitBand

STRING [text]: Type characters

STRINGLN [text]: Type + Enter

DELAY [ms]: Wait (e.g. 500)

DEFAULT_DELAY [ms]: Global delay

RANDOM_DELAY [min] [max]

REPEAT [n]: Repeat last line

HOLD [key]: Stay pressed

RELEASE: Stop all holds

PAUSE: Wait for user button

Combos: CTRL+ALT+DELETE

Media: VOLUP, VOLDOWN, MUTE

GUI / WINDOWS: Start Menu

SPECIAL KEY REFERENCE

System & Nav

  • GUI or WINDOWS
  • ESC, ENTER, TAB
  • BACKSPACE, DELETE
  • UP, DOWN, LEFT, RIGHT

Media & Function

  • VOLUP, VOLDOWN, MUTE
  • PLAY (Media Play/Pause)
  • F1 through F12
  • SPACE

Note: Use + for combos (e.g., CTRL+SHIFT+ESC). Use HOLD for persistent states.
