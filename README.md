# What is BitBand?
Compared to the previous version, this one is more practical.

It acts as a USB HID keyboard when plugged.
Then, it can either run scripts from the on-board interface or remotely
via an WiFi Access Point or by connecting it directly into a network.

It's sort of a BadUSB-style device, just bigger than a pendrive, but also (I think) more versatile :3
